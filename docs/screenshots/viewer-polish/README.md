# Viewer polish screenshots

Real captures of the built web viewer (`common/webapp/dist`) in Microsoft Edge, with terrain served from a live map and the map names, markers and players replaced by neutral placeholders. `before-*` is the viewer at the previous master commit, `after-*` is this change. Sizes are 1440x900 (desktop), 390x844 (phone) and 360x740 (narrow).

The design that drove the change is in `design/viewer-polish/`.
